# Contributing to Pulse 249

Thank you for your interest in Pulse 249.

Contributions may include bug reports, bug fixes, device support, monitoring improvements, discovery improvements, documentation, tests, UI improvements, performance work, and security improvements.

## Pull requests

Please keep pull requests focused.

Explain the problem being solved, what changed, how the change was tested, and any deployment or compatibility impact.

## Security

Never submit real passwords, API keys, private keys, SNMP communities, SSH credentials, access tokens, database dumps, or confidential network information.

Security vulnerabilities should be reported privately according to SECURITY.md.
