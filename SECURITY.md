# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities through a public GitHub issue.

If you discover a potential vulnerability in Pulse 249, report it privately to the project maintainer.

Please include the affected component, version or commit, reproduction steps, observed behavior, expected behavior, and potential impact.

Do not include real passwords, private keys, access tokens, SNMP communities, production device configurations, or confidential network information.

## Project status

Pulse 249 is currently under active development and has not yet reached its first stable release.
