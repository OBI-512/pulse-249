# Pulse 249 Community Code of Conduct

Pulse 249 aims to provide a professional, technically rigorous, and welcoming environment for people contributing to network operations software.

## Expected behavior

Participants should:

- communicate respectfully and constructively;
- focus criticism on technical ideas, code, documentation, and observable behavior rather than individuals;
- be patient with contributors from different technical, cultural, and language backgrounds;
- provide enough context for others to reproduce and understand issues;
- respect security, privacy, and confidentiality boundaries;
- avoid publishing credentials, customer information, private network data, or other sensitive operational material;
- accept maintainer decisions about project scope, safety, architecture, and release readiness even when discussing alternatives.

## Unacceptable behavior

The following are not acceptable in project spaces:

- harassment, threats, discrimination, or personal attacks;
- deliberately disruptive or abusive behavior;
- publishing another person's private information without permission;
- knowingly submitting secrets, malicious code, or confidential infrastructure data;
- using project channels to facilitate unauthorized access to systems or devices.

## Security-sensitive discussions

Potential security vulnerabilities should not be disclosed through public issues when disclosure could place users or infrastructure at risk. Follow [SECURITY.md](SECURITY.md) for reporting guidance and use sanitized examples whenever possible.

## Maintainer responsibilities

Maintainers may edit, hide, reject, or remove contributions and interactions that violate this code or place users, contributors, or infrastructure at unnecessary risk. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

## Scope

This code applies to Pulse 249 repositories, issues, pull requests, discussions, and other project-managed collaboration spaces.
